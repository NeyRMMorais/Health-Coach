# Health-Coach — Agent Instructions

## Project Overview
- **Stack**: React 19, Vite 6, Tailwind CSS v4, TypeScript, Express (`server.ts`), Firebase, `@google/genai`.
- **Entry Points**:
  - Frontend: `src/` (built via Vite)
  - Backend: `server.ts` (run via `tsx server.ts`)

## Documentation Map (Docs-as-Code)
- `README.md` — Business & technical overview, setup, and run instructions.
- `BACKLOG.md` — Living roadmap (`Up Next`, `In Progress`, `Done`).
- `docs/PRODUCT.md` — Business rules, user flows, and domain logic (when present).
- `docs/ARCHITECTURE.md` — Technical architecture, data models, and deployment (when present).

## Verification Commands
- Typecheck: `npm run lint` (`tsc --noEmit`)
- Build: `npm run build`
- Dev server: `npm run dev`
